# Vserve GEO Readiness Audit™ Tool

A consultative funnel tool that generates a professional GEO (Generative Engine Optimization) Score (0-100) to help brands understand their visibility in AI-powered search engines like ChatGPT, Perplexity, and Google AI Overviews.

## Features

- **Comprehensive Audit**: 13 high-impact questions across 4 pillars
- **Weighted Scoring**: Technical (30%) + Structure (35%) + Authority (25%) + Freshness (10%)
- **Ghost Citation Analysis**: Shows current vs. optimized AI responses
- **Personalized Recommendations**: Priority-ranked action items
- **Lead Capture**: Integrated form for follow-up

## Score Ranges

| Score | Status | Description |
|-------|--------|-------------|
| 90-100 | Elite | Brand is "AI-Native" |
| 60-89 | At Risk | Losing "Share of Answer" to competitors |
| 0-59 | Critical | Brand is invisible to generative search |

## The Four Pillars

1. **Technical AI Access** (30%) - Can AI bots crawl and parse your data?
2. **Content Extractability** (35%) - Is content structured for RAG?
3. **Entity Authority** (25%) - Are you a distinct entity in AI knowledge?
4. **Citation Health** (10%) - Are you in trusted directories?
